# Storage Architecture

The actual files are **NOT** stored inside the Spring Boot project.

Instead

```
D:\AI-Knowledge\
        uploads\
              1\
                  pdf1.pdf
                  pdf2.pdf

              2\
                  invoice.pdf

              3\
                  research.pdf
```

where

```
uploads/
      └── userId/
               └── files
```

Every user has his own folder.

---

# Database

Only metadata is stored.

Example

```
Document

id

originalFileName

storedFileName

contentType

size

uploadTime

user_id
```

No binary data inside SQLite.

# Ownership Check

Every operation checks

```
document.user.id == loggedInUser.id
```

Therefore

User A

cannot

* download User B's document

* delete User B's document

* even know it exists

This is one of the most important security checks.

# Folder Responsibilities

## DocumentController

Responsible for

* HTTP endpoints
* Request validation
* Returning ResponseEntity

No business logic.

---

## DocumentService

Responsible for

* ownership validation
* saving metadata
* deleting metadata
* retrieving metadata
* calling storage service

No file I/O here.

---

## FileStorageService

Responsible only for

* creating folders
* storing files
* reading files
* deleting files

No database code.

---

## Repository

Responsible only for SQL.

Nothing else.

---

## Mapper

Responsible only for

```
Entity

↓

DTO

↓

Entity
```

No business logic.
